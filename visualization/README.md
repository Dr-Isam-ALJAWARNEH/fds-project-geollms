📍 visualization/ - Air Quality Data Visualization
This folder contains notebooks and resources for visualizing air quality (PM2.5) data over the city of Chicago using interactive heatmaps.

📊 Contents
Visualization_AQ_data.ipynb
Jupyter notebook that:

Downloads and merges PM2.5 datasets from multiple CSV files.

Cleans the data by removing missing values.

Creates an interactive Folium HeatMap to visualize pollution levels.

Saves the output as an HTML file (pm25_heatmap_chicago.html).

🗂️ Data Source
19 CSV files from the AQ_data folder in the main dataset repository.

Hosted under:
/Datasets/AQ_data/

🗺️ Output
pm25_heatmap_chicago.html – an interactive HTML map visualizing PM2.5 concentrations.

🚀 How to Run
Open the notebook in Google Colab.

Run all cells to generate the interactive heatmap.

Download or view the generated HTML file.
